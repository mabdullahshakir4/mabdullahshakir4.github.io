# Muhammad Abdullah Shakir — Portfolio Website

Static portfolio website for GitHub Pages.

## Deploy to GitHub Pages

1. Create or open the repository: `mabdullahshakir4.github.io`
2. Upload **all files and the `assets` folder from this package to the root of the repository**.
3. Commit the files to the default branch.
4. In GitHub, open **Settings → Pages** and publish from the repository's main/default branch if it is not already publishing automatically.
5. Your site will be available at `https://mabdullahshakir4.github.io/` after GitHub finishes deploying it.

## Important

Do not upload the ZIP itself as the website. Extract it first, then upload the contents so `index.html` is at the repository root.

## Main files

- `index.html` — portfolio homepage
- `ppc-scaling.html` — Amazon PPC scaling case study
- `performance-growth.html` — multi-month portfolio analysis
- `keyword-ranking.html` — keyword ranking project
- `styles.css` — site styling
- `script.js` — navigation, scroll animation and image lightbox
- `assets/` — profile image and case-study screenshots
