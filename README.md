## Update your existing GitHub Pages site

You already have the repository: `mabdullahshakir4.github.io`.

1. Extract this ZIP on your computer.
2. Open your GitHub repository: `mabdullahshakir4.github.io`.
3. Upload **all files and the `assets` folder from this package** to the repository root.
4. When GitHub asks about files with the same names, the new versions should replace/update the existing files.
5. Commit the changes to `main`.
6. GitHub Pages should redeploy automatically.
7. Refresh `https://mabdullahshakir4.github.io/` after the deployment finishes.

## Important

`index.html` must be directly at the repository root—not inside an extra folder.
